# Поверхность атаки

Черновик этапа 0. Все внешние интерфейсы продукта: сетевые (порт, протокол, аутентификация), файловые, аргументы CLI, переменные окружения (ТЗ, раздел 9). Обновляется при любом изменении интерфейсов.

## Сетевые интерфейсы
| Компонент | Адрес по умолчанию | Протокол | Аутентификация | Эндпоинты | Этап |
|---|---|---|---|---|---|
| `aisec-gateway` | `127.0.0.1:8443` | HTTPS (TLS 1.2–1.3; HTTP без TLS отвергается) | Нет — только для разработки на этапе 0; ключи приложений — этап 1 (ИАФ.8) | `GET /healthz`, `GET /readyz`, `POST /v1/chat/completions` (прозрачный прокси на один upstream, в том числе SSE). Прочее — 404 или 405 в формате ошибок OpenAI | 0 |

`POST /v1/chat/completions` на этапе 0: только `Content-Type: application/json` (иначе 415), тело не больше `max-body-bytes` (иначе 413) и только объект JSON (иначе 400) — проверяется до обращения к провайдеру. Провайдеру уходят только заголовки `Content-Type`, `Accept`, `User-Agent`, `X-Request-Id` и перечисленные в `forward-headers`; клиентские `Authorization`, `Cookie`, `X-Forwarded-*` отбрасываются, ключ провайдера подставляет шлюз. Приложению возвращаются только `Content-Type`, `Retry-After`, `X-Request-Id` и `X-Ratelimit-*` провайдера. Ошибки связи с провайдером — 502 или 504 без внутренних подробностей. Разрыв соединения клиентом отменяет запрос к провайдеру.

**Исходящие соединения шлюза:** только на `upstream-url` (allowlist из одного адреса, ЗИ.3); переменные `HTTP_PROXY`/`HTTPS_PROXY` не используются; TLS с доверием только `upstream-ca`; таймауты на соединение и до заголовков ответа.

Общие ограничения HTTPS-сервера (`internal/httpserver`): таймаут чтения заголовков 10 с, простой соединения 120 с, заголовки до 64 КиБ, корректное завершение до 30 с. Ответы шлюза содержат `X-Content-Type-Options: nosniff`, `Cache-Control: no-store`, `Strict-Transport-Security`.

## Файлы
| Файл | Кто читает или пишет | Защита |
|---|---|---|
| Сертификаты и ключи TLS (путь задаёт администратор) | Компоненты читают сертификаты через `crypto.ReadPEMFile`, закрытые ключи — через `crypto.ReadKeyFile` | Только обычный файл, не больше 1 МиБ; проверки выполняются на открытом файле (подмена между проверкой и чтением не помогает). Ключ с доступом для группы или остальных не читается (нужно 0600 или 0400) |
| Каталог ключей стенда разработки (`.dev-keys/`) | `tools/devcerts` пишет | Каталог 0700, ключ 0600, запись через временный файл; ключ УЦ не сохраняется; каталог в `.gitignore` и закрыт для чтения ИИ-ассистентом (`.claude/settings.json`) |

## Аргументы командной строки
`aisec-gateway` — у каждого флага есть переменная окружения (раздел ниже); флаг важнее переменной. Неизвестные флаги и лишние аргументы — ошибка запуска.

| Флаг | Назначение | Проверка |
|---|---|---|
| `-listen` | Адрес и порт | `адрес:порт`; по умолчанию `127.0.0.1:8443` |
| `-tls-cert`, `-tls-key` | Сертификат и ключ TLS | Обязательны; обычный файл до 1 МиБ; ключ — права 0600 или 0400 |
| `-upstream-url` | Базовый адрес провайдера | Обязателен; только `https`, без учётных данных, параметров и фрагмента |
| `-upstream-ca` | Корневые сертификаты провайдера | Обязателен; доверие только им, системное хранилище не используется |
| `-upstream-key-file` | Ключ API провайдера | Необязателен; права 0600 или 0400 |
| `-max-body-bytes` | Предел тела запроса | 1 КиБ – 32 МиБ, по умолчанию 1 МиБ |
| `-upstream-connect-timeout`, `-upstream-header-timeout` | Таймауты к провайдеру | Больше 0 и не больше 10 мин; по умолчанию 10 с и 60 с |
| `-forward-headers` | Дополнительные заголовки для провайдера | До 16 имён; `Authorization`, `Cookie`, `Host`, `X-Forwarded-*` и заголовки соединения запрещены |

## Переменные окружения
`aisec-gateway`: `AISEC_GATEWAY_LISTEN`, `AISEC_GATEWAY_TLS_CERT`, `AISEC_GATEWAY_TLS_KEY`, `AISEC_GATEWAY_UPSTREAM_URL`, `AISEC_GATEWAY_UPSTREAM_CA`, `AISEC_GATEWAY_UPSTREAM_KEY_FILE`, `AISEC_GATEWAY_MAX_BODY_BYTES`, `AISEC_GATEWAY_UPSTREAM_CONNECT_TIMEOUT`, `AISEC_GATEWAY_UPSTREAM_HEADER_TIMEOUT`, `AISEC_GATEWAY_FORWARD_HEADERS` — те же проверки, что у флагов. Секреты через переменные окружения не передаются: только пути к файлам.
