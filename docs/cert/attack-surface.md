# Поверхность атаки

Черновик этапа 0. Все внешние интерфейсы продукта: сетевые (порт, протокол, аутентификация), файловые, аргументы CLI, переменные окружения (ТЗ, раздел 9). Обновляется при любом изменении интерфейсов.

## Сетевые интерфейсы
Заполняется в задаче 0.16 плана этапа 0.

## Файлы
| Файл | Кто читает или пишет | Защита |
|---|---|---|
| Сертификаты и ключи TLS (путь задаёт администратор) | Компоненты читают сертификаты через `crypto.ReadPEMFile`, закрытые ключи — через `crypto.ReadKeyFile` | Только обычный файл, не больше 1 МиБ; проверки выполняются на открытом файле (подмена между проверкой и чтением не помогает). Ключ с доступом для группы или остальных не читается (нужно 0600 или 0400) |
| Каталог ключей стенда разработки (`.dev-keys/`) | `tools/devcerts` пишет | Каталог 0700, ключ 0600, запись через временный файл; ключ УЦ не сохраняется; каталог в `.gitignore` и закрыт для чтения ИИ-ассистентом (`.claude/settings.json`) |

## Компоненты вне поставки
| Компонент | Интерфейс | Примечание |
|---|---|---|
| `mock-llm` (`cmd/mock-llm`) | HTTPS, по умолчанию `127.0.0.1:9443`: `GET /healthz`, `GET /v1/models`, `POST /v1/chat/completions` (в том числе SSE). CLI: `-listen`, `-cert`, `-key` | Только для разработки и e2e, в поставку и SBOM продукта не входит. Только TLS (HTTP без TLS отвергается), тело до 1 МиБ, до 256 сообщений, таймаут чтения заголовков 10 с, лимит заголовков 64 КиБ; содержимое сообщений не журналируется |
| `tools/devcerts` | CLI: `-out`, `-hosts`, `-days`, `-force` | Выпуск сертификатов стенда разработки |
| Утилиты `tools/*` | CLI | Проверки сборки; в поставку не входят |
