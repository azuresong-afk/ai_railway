## Криптопрофиль (ТЗ, раздел 10)
Реализован в `internal/crypto`; импорт `crypto/*` вне пакета запрещён линтером (`make lint-selftest` это доказывает).

| Интерфейс | Профиль `standard` | Профиль `gost` |
|---|---|---|
| `Hasher` | SHA-256 | не реализовано (этап 6) |
| `MAC` | HMAC-SHA-256, ключ не короче 32 байт и копируется при создании, проверка за постоянное время; при выводе через `fmt` и `slog` показывается только имя алгоритма, ключ не попадает в логи (`TestMACDoesNotLeakKey`) | не реализовано |
| `Random` | `crypto/rand` | не реализовано |
| `TLSProvider` | TLS 1.2–1.3 (10.3) | не реализовано; TLS с ГОСТ — на шлюзе заказчика |
| Внутренний УЦ | ECDSA P-256, серийные номера 128 бит, срок не больше 825 дней и не дольше срока УЦ; не больше 32 имён, без шаблонов `*` | — |
| `Signer`/`Verifier`, `AEAD`, `PasswordHasher` | этапы 1–2 | — |

Профиль `gost` на всё отвечает `ErrNotImplemented`, а контрактный тест `TestProfileContract` это фиксирует: профиль не может молча работать не так, как заявлено.
