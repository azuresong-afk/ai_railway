# Словарь терминов

Интерфейс и документация используют термины только в этих значениях (ТЗ, 0 и 6.7).

| Термин | Значение | Не путать с |
|---|---|---|
| Шлюз | Компонент, через который приложения обращаются к LLM | Прокси сотрудников (не входит в продукт) |
| Приложение | Зарегистрированное ИИ-приложение заказчика: чат-бот, ассистент, RAG-сервис, агент | Пользователь |
| Провайдер | Внешний или локальный API модели. Внешний — вне контура заказчика | Модель |
| Детектор | Модуль, который находит угрозу или чувствительные данные в тексте | Правило |
| Находка | Результат срабатывания детектора: тип, оценка, позиции в тексте | Событие |
| Политика | Набор правил: какие детекторы применять и что делать при срабатывании | Исключение |
| Событие | Запись об одном обработанном запросе или проверке | Оповещение |
| Оповещение | Срабатывание правила оповещения по событиям | Уведомление (доставка оповещения по каналу) |
| Инцидент | Карточка для расследования, объединяющая оповещения и события | Оповещение |
