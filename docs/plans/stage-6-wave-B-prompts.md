   - Миграции — тем же механизмом, что aisec-cli migrate. Запись в аудит — начало, итог, откат.
   - Вывод для администратора — по ТЗ 6.7, без секретов.

   - прерывание процесса между шагами — повторный запуск доводит обновление или откатывает.
   На каждый случай: прежняя версия работает, БД в прежнем состоянии, события из буфера шлюза досылаются. Тесты с БД — на живой БД, без ID строки в имени.
