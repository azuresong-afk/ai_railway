# Дорожная карта: что сделано, что дальше и зачем

Состояние на 19.10.2026. Источники: `roadmap.md`, `stage-1.md`, `parallel-stage-1.md`. Этот файл — обзор для человека, источник истины по статусам остаётся в `stage-1.md`.

## Общая картина
Продукт — шлюз-посредник между приложениями и языковыми моделями плюс веб-консоль. Шлюз проверяет запросы и ответы, прячет персональные данные, ловит промпт-инъекции и утечки. Работа идёт по шести этапам по ТЗ (раздел 14). Сейчас идёт этап 1 — ядро шлюза.

## Этап 0 — основа. Готов
Каркас репозитория, сборка и `make check`, линтеры и проверки безопасности, документы для сертификации, mock-провайдер. **Зачем:** требования безопасной разработки (ФСТЭК) действуют с первого коммита, поэтому проверки и документы нужны до появления функций.

## Этап 1 — ядро шлюза. В работе
**Цель:** шлюз, который принимает запрос в формате OpenAI, проверяет его, скрывает ПДн, блокирует инъекции, пересылает модели и проверяет ответ. Без интерфейса и сервера управления: настройки берутся из локального файла.

### В работе
- **1.19 Политики** (A4): какие детекторы включены, режимы `monitor` (только журнал) и `enforce` (блокировка), приоритеты. Зачем: пилоты начинают с мониторинга, потом включают блокировку.
- **1.25 mock-llm** (A5): имитация модели с канарейкой, вредными ссылками и вызовами инструментов. Зачем: проверить защиту ответа без реальной модели.
