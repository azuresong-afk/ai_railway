# Этап 2, волна E: промпты

Умолчания — как в `stage-2-wave-A-prompts.md`: решения Р1–Р13 из `docs/plans/stage-2.md`, интеграционная ветка `claude/stage-2-integration`, Go 1.27.3.

Правило для всех задач с API (с 2.9, ADR-0013): у каждого маршрута в `api/openapi.yaml` есть `x-permission`; новое право — строкой в `internal/auth/permissions.go`, затем `make rbac-matrix`, иначе падает контрактный тест.

Правило для задач, которые добавляют или меняют детекторы (с 2.18, ADR-0012): у каждого детектора — два эталона в `internal/integrity/selftest/vectors.go`, иначе самотест его не покрывает.

Известные нестабильные тесты: `TestRegexLinearTime`, `TestDM11_IncrementalLongListWithCode` и `TestServerSinkSplitsLargeBatch` могут падать под нагрузкой с `-race` и проходят по отдельности. Если упал один из них, перезапусти его отдельно (`go test -race -run <имя> <пакет>`) и укажи это в отчёте. Это не повод ослаблять тест или пропускать другие падения.
