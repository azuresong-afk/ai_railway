Делает B1 только после «да» владельца в потоке; без «да» — пропускает и сообщает.
- **Нумерация ревью этапа 3**: важные — `3В1`, `3В2`…, незначительные — `3Н1`, `3Н2`… (замечания A2-В*/A2-Н* потока A2 — отдельный ряд, не повторять).
