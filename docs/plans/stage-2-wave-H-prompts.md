## Принятые решения
Владелец поручил выбирать решения самому, по рекомендациям и общепринятой практике (22.10.2026). Решения ниже приняты на этом основании. Поток следует им и вопрос не задаёт; если решение противоречит ТЗ или коду, поток останавливается и сообщает об этом.

| # | Вопрос | Решение | Почему |
|---|---|---|---|
| H-Р1 | Ключ резервной копии (2.19) | Копия шифруется ключом, выведенным из парольной фразы администратора через Argon2id (параметры Р3, своя соль в заголовке). Шифрование — AES-256-GCM, заголовок с версией формата входит в AAD. Мастер-ключ установки для копии не используется. Фраза — не короче 16 символов, вводится дважды, в аргументах командной строки не принимается | Восстановление должно работать на новой установке после потери мастер-ключа. Именно для этого копия и нужна. Так принято в Vault, Bitwarden и restic |
| H-Р2 | Состав копии | Политики со всеми версиями, приложения (хеши ключей), провайдеры (секреты перешифровываются ключом копии), пользователи (хеши паролей, секреты TOTP), роли, настройки, ключ HMAC псевдонимов. События и журнал аудита в копию не входят: у аудита своя архивация (2.5), у событий — сроки хранения | ТЗ РВ.1 говорит о конфигурации. Если включить события, копия вырастет и будет хранить содержимое запросов без сроков хранения |
| H-Р3 | Восстановление | Через `aisec-cli backup restore`, только в пустую установку после `init`. В непустую — только с явным флагом, с записью в аудит до и после восстановления. Ключи шлюзов и УЦ не восстанавливаются: шлюзы регистрируются заново | Иначе восстановление тихо затирает рабочую конфигурацию. Перевыпуск сертификатов проще и безопаснее, чем перенос закрытого ключа УЦ в файле копии |
| H-Р4 | Часовой пояс и режим хранения при первичной настройке (вопрос 2.24) | В `SetupRequest` добавляются необязательные поля `timezone` (имя IANA, проверяется через `time.LoadLocation`; по умолчанию Europe/Moscow) и `retention_mode` (значение из допустимых по ТЗ 5.5; по умолчанию — значение по умолчанию из ТЗ). Ничего не задано — действуют умолчания. Позже оба поля меняются в «Администрировании» | ТЗ 6.4 требует спрашивать их при первичной настройке. Необязательные поля не ломают текущих клиентов |
| H-Р5 | Песочница без нужного словаря (отступление E1) | Экран «Политики» показывает ответ 422 как понятную подсказку со ссылкой на словари приложения. Ошибкой интерфейса это не считается | Поведение сервера принято в E1 |
