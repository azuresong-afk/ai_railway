# AISec (рабочее название)

Платформа безопасности ИИ: шлюз-посредник между приложениями и LLM (фильтрация запросов и ответов, маскирование ПДн, защита от промпт-инъекций, контроль ИИ-агентов) и веб-консоль с дашбордами, оповещениями и инцидентами. Продукт проектируется под сертификацию ФСТЭК России (уровень доверия 4).

Состояние: этап 0 «Фундамент» — план и статусы задач в [`docs/plans/stage-0.md`](docs/plans/stage-0.md).

## Документы
- Техническое задание — [`docs/SPEC.md`](docs/SPEC.md).
- Правила работы в репозитории — [`CLAUDE.md`](CLAUDE.md).
- Архитектура и решения — `docs/architecture.md`, `docs/adr/`.
- Артефакты для сертификации — `docs/cert/`.

## Требования к окружению
- Go 1.27 (версия toolchain зафиксирована в `go.mod`).
- GNU Make.
- Docker — для стенда разработки и сборки в контейнере.

## Команды
| Команда | Что делает |
|---|---|
| `make dev` | Стенд разработки: mock-llm и шлюз |
| `make test` | Модульные тесты |
| `make check` | Все проверки перед pull request: линтеры, SAST, тесты, fuzz-smoke, уязвимости, лицензии, SBOM, e2e, покрытие матрицы обнаружения |
| `make help` | Полный список целей |

## Структура
```
cmd/          исполняемые компоненты: aisec-gateway, aisec-server, aisec-cli, aisec-media, mock-llm (только для разработки)
internal/     пакеты продукта; криптография — только в internal/crypto
api/          контракт API управления (OpenAPI 3.1)
web/          веб-консоль (с этапа 2)
testdata/     корпуса детекторов, fuzz-корпуса, фикстуры
deploy/       docker compose, сборочный образ, пакеты
tools/        утилиты сборки и проверки (в поставку не входят)
docs/         ТЗ, архитектура, ADR, планы этапов, артефакты сертификации
```

## Порядок изменений
Основная ветка `main` защищена. Изменения — только через pull request с ревью владельца; коммит слияния подписывается ключом владельца (ТЗ, 8.2).
